----------------------------------------------------------------
一、这是什么
----------------------------------------------------------------

语见是一个运行在 Android 手机上的聊天客户端，用来连接你自己配置的
OpenAI 兼容接口（OpenRouter、DeepSeek 官方，或任何兼容 /v1/chat/completions
的服务）。

它的定位很明确：

  · 只做「界面 + 转发 + 本地保存」，不提供模型服务
  · 客户端不做内容审查、不做提示词改写、不做请求拦截
  · 你输入什么就发送什么，模型返回什么就显示什么
  · 所有 API Key 与你自己的账号绑定，费用由服务商收取

技术形态：WebView 界面 + 原生 HTTP 层。安装包不到 0.5 MB，
不内置任何模型、不内置任何第三方 SDK 埋点。

三、快速上手（5 步）
----------------------------------------------------------------

第 1 步：安装
  把 APK 传到手机安装（需允许「安装未知来源应用」）。
  系统要求：Android 8.0（API 26）及以上。

第 2 步：添加服务商
  打开 App → 右上角齿轮 → 服务商 → 点「OpenRouter」或「DeepSeek」
  （也可以选「自定义」填任意兼容地址）。

第 3 步：填 API Key
  点该服务商的「编辑」→ 粘贴 Key → 保存。
  Key 用 Android Keystore 加密存储，不会进入导出的会话文件。

第 4 步：拉取模型
  点「拉取模型」，客户端会请求 /v1/models 并列出可用模型；
  也可以手动填模型 ID（例如 deepseek-chat、deepseek/deepseek-v3）。

第 5 步：开始对话
  返回聊天页，在底部输入框打字，点发送。
  回车键是换行，Ctrl+回车 或点发送按钮才会发出。

四、功能说明
----------------------------------------------------------------

4.1 服务商与模型
  · 支持 OpenRouter、DeepSeek 官方，以及任何 OpenAI 兼容端点
  · 每个服务商可存多个模型，随时切换（顶部标题点一下即可）
  · 支持多个服务商并存，会话之间互不影响

4.2 对话
  · 流式输出（可关），逐字显示，40ms 批量渲染
  · 模型返回 reasoning_content 时，折叠显示为「思考过程」
  · 消息操作：复制、重新生成、朗读、搜一下
  · 长文本自动换行，代码块、表格、引用、列表均正常渲染

4.3 参数与系统提示词
  点顶部标题或齿轮进入「对话设置」，可随时调整：
  · 温度 temperature（0–2）
  · 最大输出 max_tokens（0 = 不限制）
  · top_p（-1 = 不发送该参数）
  · 上下文条数 contextLimit（0 = 用全部历史）
  · 系统提示词（每个会话独立保存，不会自动改写你的内容）
  · 联网、自动表情、自动朗读 三个开关

4.4 联网搜索（模型自主决定）
  开关打开后，客户端会向模型声明搜索工具，由模型自己判断是否搜索。
  · 支持两种触发：调用 web_search 工具，或输出 <<search:关键词>> 标记
  · 搜索结果以「【搜索结果】」消息注入，模型据此作答
  · 每轮最多搜索 2 次（防止无限循环）
  · 搜索引擎可选：Tavily / Serper / Brave（需 Key），
    DuckDuckGo / Bing / 百度（免 Key，直接抓取页面）
  · 新闻类查询会优先走新闻源（RSS / 新闻页），失败自动回落到通用搜索
  · 模型没调用但你想搜：点消息下方的「搜一下」手动触发

4.5 表情包
  · 在手机里建一个文件夹，每个子文件夹是一种情绪（开心、悲伤、傲娇…）
  · 点 ☺ →「导入文件夹」→ 图片/GIF 会被复制进应用目录
  · 导入后原文件夹删掉也不影响使用
  · 每个分类可单独设置触发概率；可删除单张或整个分类
  · 模型通过 send_sticker 工具或 [[emo:分类]] 标记发图，
    客户端从该分类里随机挑一张发出
  · 只有实际存在的分类，模型才可能发送

4.6 语音朗读（需另装引擎）
  · 推荐安装 CloneTTS（开源、离线、支持音色克隆）
  · 优先调用 CloneTTS 的本地接口（127.0.0.1:8080）；
    不可用时自动回落到系统 TTS
  · 自动按句号切分，逐句合成播放
  · 可调语速；可开启「自动朗读回复」；每条消息也能单独点「朗读」
  · 若手机里一个 TTS 引擎都没有，会提示并跳转系统 TTS 设置页

4.7 外观
  · 头像：我和 AI 分开设置，可从相册选图（自动裁成方形）
  · 气泡：我和 AI 分开选样式（经典红 / 奶白；深色 / 奶白），即时生效
  · 聊天背景：无 / 深空 / 暮色 / 青灰 / 暖沙 / 语见（狐狸）
    也可以选自己的图片，并调节遮罩浓度

4.8 会话管理
  · 左上角菜单打开会话列表，按「今天 / 昨天 / 本周 / 更早」分组
  · 重命名、删除、单独导出单个会话
  · 底部「导出全部」「导入」用于备份与迁移（JSON 格式，不含 Key）

4.9 诊断
  设置页底部的诊断区会记录最近的请求与事件（如 tools、search-start、
  tts、viewport），可一键复制。遇到问题时把这段日志贴出来，
  是最快的排查方式。

五、语见小狐狸（角色设定）
----------------------------------------------------------------

她叫「语见」，是这款软件的拟人形象，严格说是「看板娘」——
她不会代替模型回答问题，也不参与任何推理，只是软件的“脸”。

【名字】
  「语见」谐音「遇见」：说话即相见。
  也可以读作「语（言）之见」——把语言里看见的东西说出来。

【外形】
  · 红发，头发很长，发梢蓬松
  · 一对狐狸耳朵（耳内是奶白色），尾巴很大，尾尖也是奶白
  · 深红色连衣裙，配白色荷叶边、蝴蝶结发饰、铃铛项圈
  · 眼睛是偏金色的琥珀色，表情通常带点好奇

【性格】
  · 好奇、话多、爱表现，被夸了会翘尾巴
  · 偶尔有点傲娇，嘴上不承认，动作已经出卖了她
  · 遇到不懂的事情会先去看一眼，而不是瞎猜

【她与功能的对应】（这是设定，不是技术实现）
  · 狐狸耳朵 —— 敏锐，对应「联网搜索」
  · 大尾巴 —— 表达欲，对应「表情包」
  · 脖子上的铃铛 —— 提醒，对应「语音朗读」
  · 扒在气泡上边缘 —— 她总是趴在你要看的那句话旁边

【她在界面里出现的位置】
  · 空对话页：全身站立，轻轻上下浮动
  · 设置页顶部：从卡片底部探出来
  · 每条 AI 消息：圆形小头像
  · 等待回复时：思考表情 + 三个跳动的点
  · 出错时：生气表情
  · 最新一条回复：扒在气泡上边缘

【可以换掉她吗】
  可以。设置 → 头像 → 更换，选你自己的图片即可。
  气泡、背景、表情素材也都来自本地文件，你完全可以替换成别的形象。

六、已知限制
----------------------------------------------------------------

· 只支持 Android 8.0 以上
· 不含任何模型，没有配置服务商时无法对话
· 免 Key 搜索依赖抓取网页，遇到反爬（验证页、302 跳转）会失败，
  稳定性不如付费 API；需要稳定请配 Tavily
· 语音朗读依赖外部 TTS 引擎；未安装时会提示
· 语音目前不支持后台/锁屏持续朗读（切到后台会停）
· 不支持多账号同时登录同一服务商（可添加多个服务商条目绕过）
· 图片理解取决于模型是否支持视觉；客户端只负责把图片编码进请求


----------------------------------------------------------------
七、隐私与安全
----------------------------------------------------------------

· API Key：使用 Android Keystore（AES-256-GCM）加密存储，
  不写入会话文件，导出/导入不包含 Key
· 会话数据：全部保存在本机应用私有目录，不上传任何服务器
· 网络请求：只发往你自己配置的服务商地址，以及（开启搜索时的）
  搜索服务地址；没有第三方统计、没有埋点上报
· 表情包与头像：保存在应用私有目录，不上传
· 卸载应用会清除以上全部数据（导出的 JSON 除外）

八、常见问题
----------------------------------------------------------------

Q: 提示「请先配置服务商」？
A: 去设置里添加服务商并填写 Key，然后在对话设置里选一个模型。

Q: 搜索返回「搜索失败」？
A: 抓取式搜索引擎不稳定。打开诊断看具体哪一步失败；
   建议配置 Tavily Key（免费额度每月约 1000 次）。

Q: 模型说它没有联网能力？
A: 确认底部 🌐 是开启状态（高亮）。提示词里已明确告知模型具备搜索能力，
   但个别模型仍可能不调用；可以点「搜一下」手动触发。

Q: 表情包不出现？
A: 三步排查：① 是否已导入分类 ② 是否打开「自动表情」
   ③ 模型是否输出了 send_sticker 或 [[emo:分类]]。

Q: 朗读没声音？
A: 先确认手机里装没装 TTS 引擎（设置 → 语音朗读，会显示引擎数量）。

Q: 换手机会丢数据吗？
A: 用「导出全部」生成 JSON，在新设备上「导入」即可（不含 Key）。
